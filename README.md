### 🔭 Intro.

팀과 제품에 **가치 있는 문제를 찾아 구조로 푸는** 서버 엔지니어 손주선입니다.

인젠트에서 금융·공공·대기업 **EAI 솔루션** 백엔드를 개발하고 있습니다. 대용량 채널이 유량 제한 없이 요청을 받아 피크 타임에 서버가 다운되던 문제를, **Redis·Redisson 분산락 기반 채널별 유량 제어**로 풀어 다운타임을 제거하고 이중화 환경의 가용성을 지킨 경험이 있습니다.
